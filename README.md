# Baseline Sales Dashboard

A live year-over-year performance dashboard for bars and restaurants, built on POS exports and GitHub Pages.

**All data in this repository is synthetic.** "Copper Still Taproom" is a fictional venue, and every sales figure, menu item price, and cost in this demo was generated for demonstration purposes.

## What it shows

Year-over-year revenue, sales mix by category, top items, operations metrics, guest traffic, monthly detail, item-level sales, and a menu pricing analysis with a cost-target simulator.

## How it updates

Monthly POS CSV exports are dropped into the `/data` folder (or uploaded with the included updater tool), and the dashboard rebuilds itself on the next page load.
